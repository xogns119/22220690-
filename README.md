# 협동 미로탈출게임 co-op-maze-escape
# 22220690/이태훈
게임: 2인 협동, 미로탈출게임 닉네임 설정 방 생성(방장 제외 코드 입력 후 입장) 서로 다른 출발점에서 시작. WASD로 캐릭터 움직이고, 장애물을 피하면서 코인 획득하며 종점에 도달. 점수획득 사망시 해당 스테이지의 각자 랜덤 출발점에서 처음부터 다시 시작.
서버가 해야할 일: 닉네임 중복 확인, 닉네임 등록 고유한 방 입장 코드 생성 및 관리, 세션 연결 맵 동기화 , wasd이동 및 장애물 충돌 판정, 종점 도착 시 클리어 이벤트 표시 코인 개수로 점수 산정 및 랭킹 업데이트 플레이어 사망 이벤트 수신 시 게임 상태 초기화
